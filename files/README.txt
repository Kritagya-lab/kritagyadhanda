Put your CV here.

1. Save your CV as a PDF.
2. Name it "CV.pdf" (or any name you like).
3. If you use a different name, open js/data.js and update:
      cv.file  and  links.cv
   to match the new file name, e.g. "files/Kritagya_Dhanda_CV.pdf".

You can delete this README.txt file once your CV is added.
